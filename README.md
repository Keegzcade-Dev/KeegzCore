# keegzcore
Universal arcade-input controller for accessible gaming and rehab.
Built by KeegzCade (YouTube).

## What it is
Keegzcade Universal Controller V1 (RP2350A): 24 digital + 4 analog
inputs, MIDI/HID, GameCube connector, RGB LED and buzzer.

## Status
- V1 (RP2350A): 24 digital + 4 analog inputs, first draft prototyped on a Pico
- V2 (RP2350B): planned, with more power, more connections and more capabilities
